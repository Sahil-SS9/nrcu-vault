# Style and ensemble references

Style variants and multi-character examples are local production inputs.

- Give each style a stable ID and one visual-medium description.
- Keep style separate from character identity and outfit variants.
- For ensemble images, record the left-to-right character mapping, scale, pose, outfit and location.
- Use no more than two or three principal characters per early shot.

The actual style and ensemble records will be created after the pending reference review.
