# Private character-reference intake

Create one folder per approved character by copying `manifest.yaml` from this template.

Rules:

- Keep supplied source files unchanged.
- Use stable `character_id` and `variant_id` values.
- Separate identity from visual style.
- Record multi-character examples in `ensemble_references` with explicit identity mapping.
- Do not load all 10–15 characters into one generation; select only the cast present in the shot.
- Keep `publish_allowed: false` for this personal local workflow.

Character ingestion stops at this gate until Sahil supplies and approves the reference information.
